# stomp-city

Kaiju smash fitness game, third person from behind the monster. Arrives in milestone 3: free movement with lean steering, swipe, stomp, 3-minute rounds with time bonuses capped near 5 minutes, 60 s rest between rounds.

When this folder gets an `index.html` with the `<!-- rep-engine:inline -->` placeholder, the build step will produce `dist/stomp-city.html`.
